Connect this panel to your bot

The panel needs a key from GitHub so it can save your choices. It stays in this browser and is never sent anywhere except GitHub.

  1. Open the GitHub key page.
  2. Name it VOX panel. Set the expiry to the longest allowed.
  3. Under Repository access choose Only select repositories and pick vox_cinema.
  4. Under Permissions open Repository permissions, find Contents and set it to Read and write.
  5. Press Generate token, copy the key, and paste it below.
